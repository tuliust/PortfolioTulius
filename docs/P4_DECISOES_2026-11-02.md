# P4 — Decisões vigentes do proprietário (02/11/2026)

**Natureza:** escolha de prioridades e preparação técnica, não autorização de migração, escrita no Supabase de produção, criação de infraestrutura, mudança de RLS/Auth ou substituição de arquivos.

| Questão | Decisão explícita | Situação |
| --- | --- | --- |
| 1. Piloto de coleções | A — **Formação/A** | Comparação pronta; 6 divergências pedem aceite |
| 2. Campos de experiências | Empresa, cargo, localização, período, projetos e realizações, fotografias/logos/galerias. Descrição da trajetória vigente | Campos registrados; escopo comum vs por empresa **não informado** |
| 3. Retratos | A — proprietário confirma 3 correspondências atuais | Arquivos estáticos conferidos; vinculação por ID pendente |
| 4. Textos alternativos | C — **manter** os metadados atuais | Não editar os 14 registros triados |
| 5. Staging | A — planejar staging **isolado, com dados fictícios** | Plano concluído; nenhum projeto criado |
| 6. SEO | A — propor deploy automático seguro **após publicar** SEO | Proposta concluída; webhook não instalado |
| 7. Segurança | A — preparar plano, **sem** alterar configurações | Plano concluído; políticas/Auth intactos |
| 8. Performance | A — apenas mudanças técnicas **sem alteração visual** | Plano concluído; LCP ≤2,5 s pendente |

As seis decisões editoriais anteriores continuam em vigor: integrar por bloco, aprovar divergências uma a uma, preservar conteúdo publicado e fotos, e manter o fluxo de salvamento/publicação até aprovação de mudanças específicas.

**Ponto em aberto:** escolher se os campos adicionais das seis experiências serão **os mesmos nas seis** ou **diferentes por empresa**. Nenhuma sincronização adicional será ativada sem isso e sem aprovação de diferenças.
